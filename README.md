# 🌍 AirSense AI

An AI-powered Urban Air Quality Intelligence Platform that helps city administrators monitor air quality, predict AQI spikes, and provide personalized health advisories to citizens.

---

## Problem Statement

Build an AI platform that moves cities from reactive pollution monitoring to proactive intervention using geospatial intelligence, predictive analytics, and AI-powered citizen communication.

---

## Core Components

### 1. Geospatial AQI Dashboard

- Live AQI visualization
- Ward-level color coding
- Interactive pollution map

### 2. Predictive Alert Agent

- Forecast AQI 24 hours ahead
- Generate enforcement priorities
- AI-powered recommendations using Groq

### 3. Citizen Advisory Bot

- WhatsApp-style chatbot
- Personalized health advisories
- Location-aware recommendations
